How it works

The cleaning engine is a Python package that runs inside the page through Pyodide (Python compiled to WebAssembly). The same package works from the command line, so a folder of files can be cleaned in one command. Nothing is uploaded: there is no server.

Sample files are synthetic: every name, email and phone number is invented.
